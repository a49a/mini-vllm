# Code of conduct / 行为准则

Please treat contributors and users with respect. Discuss technical ideas and code behavior rather than personal traits. Harassment, threats, discriminatory language, and publishing another person's private information are not welcome. Maintainers may edit or remove comments and limit participation when needed to keep collaboration constructive.

请尊重贡献者和使用者，围绕技术观点及代码行为讨论，避免人身攻击、骚扰、威胁、歧视或公开他人隐私。维护者可为保持建设性协作而编辑、删除评论或限制参与。

If you experience a problem, contact a maintainer privately through their GitHub profile when possible. A public issue may be used for general process concerns, without posting private information. Maintainers will review reports and respond proportionately to the behavior and its impact.

遇到问题时尽量通过 GitHub 个人资料中的私密渠道联系维护者；一般流程问题可公开讨论，但不要公开私人信息。
